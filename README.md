# NovaStore

## Description

NovaStore is a responsive e-commerce web application built with React, JavaScript, and CSS.

The application allows users to explore a product catalog, search for products, filter by category, and sort items by price or name.

Users can also view detailed product information, add products to a shopping cart, adjust quantities, and remove items.

The shopping cart uses localStorage to preserve its contents even after refreshing the page.

NovaStore was developed as a portfolio project to demonstrate practical skills in React development, component-based architecture, state management, and responsive web design.

## Features

- **Product Catalog:** Browse a collection of products.
- **Product Details:** View product descriptions, prices, categories, and stock information.
- **Product Search:** Find products by name.
- **Category Filtering:** Filter products by category.
- **Product Sorting:** Sort products by price or name.
- **Shopping Cart:** Add and remove products.
- **Quantity Management:** Increase or decrease product quantities.
- **Cart Total:** Automatically calculate the total price.
- **Cart Persistence:** Save shopping cart data using localStorage.
- **Responsive Design:** Adapt the layout to desktop, tablet, and mobile screens.
- **Client-Side Routing:** Navigate between pages using React Router.

## Technologies Used

- React
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
- React Router
- Context API
- localStorage

## Installation

To run this project locally, follow these steps:

### 1. Clone the repository

```bash
git clone https://github.com/archermdev38/novastore.git
```

### 2. Navigate to the project directory

```bash
cd novastore
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.
